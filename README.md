# MeuNegocioProjetoIntegrador

## Estatus : Em desenvolvimento

O projeto meu Negocio e uma ferramenta   
de gerenciamento de pequenos negocios   
na qual facilita a pequenos vendedores   
e a fornessedores de servicos gerenciaren seus negocios    
  
## Funcionalidades :   
  
- Manter um registro solido dos dados dos clientes  
- Gerenciamento inteligente de requisicoes
- Manter um cadastro inteligente dos produto e servicos fornesidos
- Criar um pdf com os dados das requisicoes
  
## Tecnologias usadas :   
- Linguagen Java
- Interface Grafica Java swing
- Banco de dados Mysql
- ORM Hibernate

## Plataforma alvo :
- JVM Multiplataforma
